# Praxissoftware

Diese APIs verwendet eine Praxissoftware (Software des Zahnarztes). Dafür wird ein [Praxis-Schlüssel](./index.md#praxis-schlüssel) benötigt.

| Dokument | Beschreibung |
| --- | --- |
| [Aufträge an Condent senden](./order-create-api.md) | Patienten und Aufträge erstellen, Dateien hochladen |
| [Billing Events API](./billing-events-api.md) | Änderungen an Leistungen (Lieferscheine, Rechnungen usw.) abfragen |
| [Rechnungs- und Lieferschein-XML](./billing-document-xml.md) | XML-Format für Rechnungen und Lieferscheine im PDF |
