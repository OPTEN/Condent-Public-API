# Laborsoftware

Diese APIs verwendet die Software eines Labors, z.B. ein ERP. Sie benötigen einen [Labor-Schlüssel](./index.md#labor-schlüssel).

| Dokument | Beschreibung |
| --- | --- |
| [Order Events API](./order-events-api.md) | Aufträge und Folgeereignisse aus Condent übernehmen |
| [Billing Import API](./billing-import-api.md) | Leistungen (Kostenvoranschlag, Rechnung usw.) inkl. Dateien nach Condent zurückspielen |
